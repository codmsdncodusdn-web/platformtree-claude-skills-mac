# 무엇을 자르고 무엇을 남길까

원칙: **의미 있는 말은 절대 지우지 않는다. 애매하면 남긴다.**
잘못 지운 말은 시청자가 바로 눈치채지만, 남겨 둔 "음" 하나는 거의 티가 나지 않는다.

## 지운다

| 종류 | 예 |
|---|---|
| 혼자 떨어진 군말 | "그래서 **음** 제가", "**어…** 오늘은" |
| 말을 시작하다 끊은 조각 | "이건 **진짜 그 이**… 이건 진짜 중요해요" → 앞 조각 삭제 |
| 다시 말한 문장 (NG 테이크) | 같은 문장을 두 번 말했으면 **마지막만** 남긴다 |
| 촬영 멘트 | "**다시 할게요**", "**잠깐만**", "**컷**", "**이거 찍히고 있나?**" |
| 앞뒤 무음 | 스크립트가 알아서 자른다 |

## 문맥을 보고 정한다

같은 글자라도 뜻이 있으면 남긴다.

| 말 | 군말이라 지움 | 뜻이 있어 남김 |
|---|---|---|
| 그 | "**그** … 제가 써 보니까" (뒤에 꾸밀 말이 없음) | "**그** 사람이", "**그** 방법은" |
| 저 | "**저**… 이게 뭐냐면" | "**저**는", "**저** 영상" |
| 이제 | "**이제** 그래서 **이제**" (습관처럼 반복) | "**이제** 끝났습니다", "**이제**부터" |
| 아 | "**아**… 그러니까" | "**아**, 그렇구나!" (감탄·반응) |
| 뭐 | "**뭐** 그냥 해 보면" | "**뭐**가 문제냐면" |
| 약간·막 | 습관처럼 계속 나올 때만 | "**약간** 싱겁다" (정도를 나타냄) |

판단 요령: **그 말을 빼고 문장을 읽었을 때 뜻이 똑같으면 군말**이다.

## 지우지 않는다

- 군말을 **단어로 말한** 경우: "**음, 어** 같은 군말을 잘라 줘요", "'**그**'를 자주 쓰는 버릇". 스크립트는 이것도 `[자동 삭제]`로 넣으니 꼭 빼 준다.
- 웃음, 일부러 둔 쉼(강조 직전의 1초 침묵 등). 사용자가 "여운 살려줘"라고 하면 강도를 약으로 바꾼다.
- 질문과 대답 사이의 반응("네", "맞아요"). 인터뷰·대화 영상이라면 특히 조심한다.
- 숫자·이름·고유명사가 들어간 문장 조각. 말이 꼬여 보여도 정보가 있으면 남기고 사용자에게 알린다.

## 받아쓰기 한계 (알고 쓰기)

- Whisper는 "음, 어"를 빼고 받아쓰는 버릇이 있다. 그래서 `hidden`의 `[군말 소리]` 후보를 같이 본다.
- 같은 문장을 똑같이 반복하면 Whisper가 하나로 합쳐 받아쓴다. 그래서 `[받아쓰지 못한 말]` 후보가 생긴다.
- 단어 시간은 0.1초 안팎으로 어긋날 수 있다. 스크립트가 자르는 지점을 가까운 조용한 곳으로 옮겨 주지만, 마무리가 중요한 영상이면 XML로 편집툴에서 확인하라고 안내한다.
