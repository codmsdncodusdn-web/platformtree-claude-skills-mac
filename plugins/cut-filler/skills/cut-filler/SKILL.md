# 군말·무음 컷편집

말하는 영상을 받아 **군말(음·어) · 무음 · NG 테이크**를 잘라낸다.
판단(무엇을 지울지)은 Claude가, 실제 자르기는 스크립트가 한다.

이 문서에서 `CUT` = `node "<이 스킬 폴더>/scripts/cut.mjs"`
- `<이 스킬 폴더>`는 이 SKILL.md가 있는 폴더의 절대경로다 (스킬을 불러올 때 알려주는 base directory).
- 경로에 공백·한글이 있으니 **항상 큰따옴표로 감싼다.**
- 모든 명령은 실패하면 ❌ 원인과 👉 다음 할 일을 한국어로 출력한다. 그 안내를 따른다.

## 0. 환경 점검 (세션에서 처음 한 번)

`CUT doctor`
- ❌가 있으면 사용자에게 알리고 `CUT doctor --fix`로 자동 설치한다 (받아쓰기 모델 약 570MB 다운로드, 처음 한 번만).
- Node.js나 FFmpeg가 없다고 나오면, 출력된 설치 명령을 사용자에게 보여주고 **허락을 받은 뒤** 실행한다.
  설치 후에는 Claude 앱을 껐다 켜야 할 수 있다고 안내한다.

## 1. 받아쓰기

`CUT transcribe "<영상 경로>" [--prompt "고유명사, 브랜드명"]`
- 영상 옆에 `<영상이름>_cut/` 작업 폴더가 생긴다. 이후 명령은 이 폴더를 인자로 받는다.
- 영상에 나오는 고유명사(제품명·툴 이름·사람 이름)를 알면 `--prompt`로 넘긴다.
- 1분 영상에 약 1~2분 걸린다. 기다리는 동안 사용자에게 진행 중이라고 알린다.

## 2. 컷 계획

`CUT plan "<작업폴더>" [--level 약|중|강]`
- 강도: **약**(0.6초 넘는 무음만), **중**(0.4초, 기본), **강**(0.25초, 아주 타이트). 사용자가 말하지 않으면 중.
- 출력과 `edl.json`의 `suggestions`를 보고 판단한다:
  - `fillers` — 받아쓴 군말. `[자동 삭제]`(음·어 등)는 이미 `dropWords`에 들어가 있다. `[문맥 확인]`(그·저·이제·뭐 등)은 문맥을 보고 군말일 때만 추가한다.
    `[자동 삭제]`도 앞뒤 문맥을 꼭 본다. "음, 어 같은 군말을"처럼 **군말을 단어로 말한 경우**는 `dropWords`에서 뺀다.
  - `hidden` — 받아쓰기엔 없지만 소리가 나는 틈.
    - `[군말 소리]`: 앞뒤가 무음으로 떨어진 짧은 소리. 대부분 Whisper가 빼먹은 "음…", "어…"다.
    - `[받아쓰지 못한 말]`: 같은 문장을 반복하면 Whisper가 하나로 합쳐 받아쓴다. 앞뒤 문맥에서 같은 말이 반복된 흔적이 보이면 지운다.
  - `retakes` — 같은 말로 다시 시작한 문장. **마지막 테이크만 남기고** 앞 테이크를 지운다.
- **반드시 `transcript.txt`를 직접 읽고** 판단한다. 판단 기준은 [RULES.md](RULES.md)를 따른다.
- 결정한 내용을 `edl.json`에 쓴다:
  ```json
  "dropWords": [[15, 15], [40, 52]],   // 지울 단어 번호 구간 [시작, 끝]
  "dropTimes": ["h1", "h3"]            // 지울 소리 틈 번호 (또는 [시작초, 끝초])
  ```
  `keep`(무음 컷 결과)은 손대지 않는다.

## 3. 적용

`CUT apply "<작업폴더>"` (편집툴 XML이 필요 없으면 `--no-xml`)

결과물 (작업 폴더 안):
| 파일 | 내용 |
|---|---|
| `<영상이름>_cut.mp4` | 컷 편집된 영상 (원본 해상도 유지) |
| `<영상이름>_cut.xml` | 프리미어 프로·다빈치 리졸브에서 가져오기 → 컷이 적용된 시퀀스 (원본 파일을 그대로 참조) |
| `report.txt` | 원래 길이 → 결과 길이, 지운 말·소리 목록 |
| `transcript_cut.txt` | 컷 후 받아쓰기 (말이 자연스럽게 이어지는지 확인용) |

## 4. 자체 점검 → 보고

1. `transcript_cut.txt`를 읽고 문장이 자연스럽게 이어지는지 확인한다. 의미 있는 말이 빠졌으면 `dropWords`에서 빼고 다시 apply.
2. 리포트에 `⚠️ 무음 컷에 같이 잘린 것 같은 단어`가 있으면 확인한다. 빠지면 안 되는 말이면 `CUT plan --level 약`으로 다시 계획하거나 사용자에게 알린다.
3. 사용자에게 보고한다:
   - 결과 영상 경로, **원래 길이 → 결과 길이 (몇 % 줄었는지)**
   - 지운 것 요약 (예: "군말 12곳, 무음 23곳, NG 테이크 2개")
   - 애매해서 남긴 부분이 있으면 그것도 알린다.
   - "더 타이트하게 / 이 부분은 살려줘" 같은 요청을 받을 수 있다고 안내한다.

## 피드백 반영

| 요청 | 할 일 |
|---|---|
| 더 타이트하게 / 덜 자르게 | `CUT plan --level 강` (또는 약) → apply. 정해 둔 dropWords는 유지된다 |
| 이 부분 살려줘 | 해당 구간을 `dropWords`/`dropTimes`에서 빼고 apply |
| 이 말도 지워줘 | `transcript.txt`에서 단어 번호를 찾아 `dropWords`에 넣고 apply |
| 처음부터 다시 | `CUT plan --reset` |
| 프리미어에서 마무리할게요 | XML 가져오기 방법 안내: 파일 → 가져오기 → `_cut.xml` 선택 |
